# IEEE 754 单精度浮点数软件仿真

本项目用 32 位 x86 汇编程序实现 IEEE 754 单精度浮点数的表示和四则运算。程序提供字符菜单，输入十进制实数字符串后，使用整数运算转换为 IEEE 754 单精度编码，并以二进制和十六进制输出。

## 文件

- `softfloat_ieee754.c`：整数算法参考实现，不使用 `float`、`double` 或浮点运算。
- `softfloat_ieee754.s`：由 MinGW GCC 生成的 80x86 汇编源码，可作为提交和检查的汇编文件。
- `softfloat_ieee754.exe`：编译后的交互式程序。
- `build.bat`：重新生成汇编文件并编译可执行程序。

## 编译运行

```bat
build.bat
softfloat_ieee754.exe
```

如果需要使用图形界面，运行：

```bat
softfloat_gui.exe
```

GUI 版本提供两个输入框和五个按钮：

- `转换 A`：把输入 A 转换为 IEEE 754 单精度编码。
- `A + B`、`A - B`、`A × B`、`A ÷ B`：对输入 A 和输入 B 执行四则运算。

结果框会显示操作数和运算结果的十六进制编码及二进制编码。

## 功能

1. 十进制实数转换为 IEEE 754 单精度表示。
2. 支持二进制输出，格式为 `符号位 指数位 尾数位`。
3. 支持十六进制输出，格式为 `0xXXXXXXXX`。
4. 支持单精度浮点数加、减、乘、除。

## 实现说明

- 十进制输入按字符串解析，整数部分和小数部分都用整数累计，小数最多保留 9 位。
- 内部保存的是 IEEE 754 单精度的 32 位编码，而不是硬件浮点变量。
- 加减法通过拆分符号位、阶码、尾数，完成对阶、尾数加减、规格化和舍入。
- 乘除法通过整数乘除得到有效尾数，再规格化和舍入。
- 舍入方式采用“就近舍入，正好一半时舍入到偶数”。
- 特殊值处理包括零、无穷大和 NaN。
- 汇编检查中不应出现 `fld`、`fst`、`fadd`、`fsub`、`fmul`、`fdiv`、`addss`、`mulss`、`divss` 等浮点指令。
