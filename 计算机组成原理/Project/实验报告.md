# IEEE 754 单精度浮点数软件仿真实验报告

## 一、项目目标

本项目采用软件仿真的方式实现 IEEE 754 单精度浮点数的表示和运算。在假设没有浮点硬件支持的条件下，程序只使用整数运算完成十进制输入到 IEEE 754 编码的转换，并实现加、减、乘、除四则运算。

## 二、开发环境

- 操作系统：Windows
- 汇编平台：80x86，MinGW GCC 生成/编译汇编源码
- 主要文件：
  - `softfloat_ieee754.s`：80x86 汇编源码
  - `softfloat_ieee754.exe`：可执行程序
  - `build.bat`：编译脚本

## 三、功能设计

程序提供字符界面和 Windows GUI 两种交互方式，提供以下功能：

1. 输入一个十进制实数，输出其 IEEE 754 单精度二进制和十六进制表示。
2. 输入两个十进制实数，完成单精度加法。
3. 输入两个十进制实数，完成单精度减法。
4. 输入两个十进制实数，完成单精度乘法。
5. 输入两个十进制实数，完成单精度除法。

二进制输出按 `符号位 指数位 尾数位` 分组显示，便于观察 IEEE 754 的三个字段。

GUI 版本文件为 `softfloat_gui.exe`，窗口中包含输入 A、输入 B、转换按钮、四则运算按钮和结果显示框。GUI 仅负责交互显示，底层 IEEE 754 转换和运算仍调用整数仿真算法。

## 四、核心算法

### 1. 十进制转 IEEE 754

程序把用户输入作为字符串处理，分别解析符号、整数部分和小数部分。小数部分最多保留 9 位十进制数字，然后构造整数分子 `num` 和分母 `den`，用整数比例 `num / den` 表示输入值。

之后通过移位规格化，使比例值落在 `[1, 2)` 区间，得到无偏阶码；再逐位生成 23 位尾数字段，并使用“就近舍入，正好一半时舍入到偶数”的规则完成舍入。

### 2. 加减法

加减法先拆分两个操作数的符号位、阶码和尾数。对于规格化数，尾数补上隐藏的最高位 `1`。然后执行：

1. 比较阶码并对阶；
2. 符号相同则尾数相加，符号不同则尾数相减；
3. 对结果进行规格化；
4. 舍入并重新打包为 32 位 IEEE 754 编码。

减法通过改变第二个操作数的符号位后调用加法实现。

### 3. 乘法

乘法先将两个 24 位有效尾数相乘，得到最多 48 位中间结果。结果符号为两个操作数符号异或，阶码为两个阶码相加。随后根据乘积最高位进行规格化、舍入和打包。

### 4. 除法

除法使用整数长除法思想。先将被除数尾数左移，保留足够的保护位，再除以除数尾数，得到带扩展位的有效尾数。结果符号为两个操作数符号异或，阶码为两个阶码相减。最后进行规格化、舍入和打包。

### 5. 特殊值

程序对零、无穷大和 NaN 做了基本处理。例如：除以零返回无穷大，`0 / 0`、`∞ - ∞` 返回 NaN。

## 五、浮点指令限制

实现代码不使用 `float` 或 `double` 类型，也不调用浮点输入输出格式。生成的汇编文件检查中未出现常见浮点指令，例如：

- x87：`fld`、`fst`、`fadd`、`fsub`、`fmul`、`fdiv`
- SSE：`addss`、`subss`、`mulss`、`divss`、`movss`

因此浮点表示和运算由整数指令模拟完成。

## 六、测试样例

| 功能 | 输入 | 结果十六进制 |
| --- | --- | --- |
| 转换 | `1.5` | `0x3FC00000` |
| 加法 | `1.5 + 2.25` | `0x40700000` |
| 减法 | `5.5 - 2.25` | `0x40500000` |
| 乘法 | `1.5 * 2.0` | `0x40400000` |
| 除法 | `7.0 / 2.0` | `0x40600000` |

这些结果分别对应十进制的 `1.5`、`3.75`、`3.25`、`3.0` 和 `3.5`，符合 IEEE 754 单精度编码。

## 七、运行方法

在项目目录中执行：

```bat
build.bat
softfloat_ieee754.exe
softfloat_gui.exe
```

根据菜单输入功能编号和十进制实数即可。
