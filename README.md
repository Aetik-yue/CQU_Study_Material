## ⚙️ 使用说明

```bash
# 克隆本仓库
git clone https://github.com/Aetik-yue/CQU_Study_Material.git

# 如需拉取最新更新
git pull origin main
```

> ⚠️ **仓库体积提示**：仓库内含大量课件、PDF 与视频，首次克隆体积较大（GB 级），建议按需稀疏检出单个课程：
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/Aetik-yue/CQU_Study_Material.git
> cd CQU_Study_Material
> git sparse-checkout set 计算机网络 操作系统
> ```

## 🤝 如何贡献

欢迎各位同学通过 Pull Request 分享你的学习资源！

1. **Fork** 本仓库
2. 创建你的分支：`git checkout -b feature/add-course`
3. 提交你的资料：`git commit -m "添加xxx课程资料"`
4. 推送到你的仓库：`git push origin feature/add-course`
5. 发起 **Pull Request**

> 📎 提交前请确认单个文件小于 100 MB；超出请使用 [Git LFS](https://git-lfs.com/) 或提供网盘链接。
