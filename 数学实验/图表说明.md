
## 图表生成脚本

所有图表由 `generate_plots.py` 脚本生成，使用 Python 的 matplotlib 库。

**运行方式**:
```bash
py generate_plots.py
```

**输出目录**: `figures/`

## 图表设计特点

1. **颜色搭配**: 使用专业配色方案，区分不同数据系列
2. **中文字体**: 使用 SimHei（黑体）确保中文正常显示
3. **数据标注**: 关键数据点直接标注数值，便于阅读
4. **网格线**: 添加适当的网格线辅助读数
5. **图例说明**: 所有图表均包含清晰的图例和标题
6. **分辨率**: 所有图片输出为 300 DPI，满足印刷要求
