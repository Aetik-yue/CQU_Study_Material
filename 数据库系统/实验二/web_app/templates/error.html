数据库连接失败

无法连接到 OpenGauss 数据库服务器

请检查 app.py 中的数据库配置：

DB_CONFIG = {
    'host': 'localhost',
    'port': 26000,
    'database': 'employee_db',
    'user': 'omm',
    'password': 'your_password'
}
常见问题：
  • 数据库服务是否已启动？
  • 主机地址和端口是否正确？
  • 用户名和密码是否正确？
  • 防火墙是否允许连接？
如果数据库在远程服务器：
方法 1：修改 host 为服务器 IP
'host': 'your-server-ip'

方法 2：使用 SSH 隧道
ssh -L 26000:localhost:26000 user@server-ip
重新加载
